# 🩺 API Teleconsultas

API REST desenvolvida para gerenciar **teleconsultas nas áreas de nutrição 🥗 e psicologia 🧠**.  
O sistema permitirá o gerenciamento de **pacientes, profissionais da saúde e agendamentos de consultas online**, oferecendo suporte para plataformas de atendimento remoto.

---

## ⚙️ Funcionalidades

- 👤 Cadastro e gerenciamento de pacientes  
- 🧑‍⚕️ Cadastro e gerenciamento de profissionais 
- 📅 Agendamento de teleconsultas  
- 📋 Histórico de consultas  
- 🔐 Autenticação e autorização de usuários  

---

## 🚀 Tecnologias utilizadas

- 🐘 **PHP**
- ⚡ **Laravel**
- 🗄️ **MySQL**
- 🌐 **REST API**
- 🔑 **Laravel Sanctum**
